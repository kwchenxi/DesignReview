# 设计对比问题分类标准

## 问题分级体系

### 严重（Critical） - 优先级：最高

#### 特征
- 功能缺失或无法使用
- 主要UI组件完全缺失
- 颜色完全错误导致可访问性问题
- 布局严重错乱影响操作

#### 典型问题
- **按钮/链接无法点击**：交互元素功能失效
- **主要内容区域缺失**：页面核心内容未实现
- **可访问性问题**：对比度低于WCAG AA标准
- **导航无法使用**：影响页面切换或功能访问

#### 修复标准
- 必须在发布前修复
- 影响核心用户体验

---

### 主要（Major） - 优先级：高

#### 特征
- 视觉显著差异但功能可用
- 布局错位影响美观度
- 文字样式显著差异
- 间距和排列不匹配

#### 典型问题
- **布局错位**：元素位置明显偏移（>10px）
- **颜色不一致**：品牌色使用错误或明显偏差
- **字体差异**：字重、字号、字体族不匹配
- **间距不一致**：元素间距显著不匹配设计稿
- **图片质量**：图片模糊或拉伸变形

#### 修复标准
- 应在当前迭代中修复
- 影响用户对产品的专业印象

---

### 次要（Minor） - 优先级：中

#### 特征
- 细微颜色差异
- 小间距偏差
- 次要样式差异
- 不影响功能和主要外观

#### 典型问题
- **细微颜色偏差**：色差值ΔE < 10
- **小间距偏差**：偏移5-10px
- **圆角轻微差异**：圆角大小偏差较小
- **阴影细微差异**：阴影强度或模糊度稍有不同
- **图标细节**：图标线条粗细或细节不一致

#### 修复标准
- 可在后续迭代中优化
- 不影响核心功能和使用

---

### 建议（Suggestion） - 优先级：低

#### 特征
- 可优化项
- 增强建议
- 设计一致性改善
- 用户体验细节提升

#### 典型问题
- **可优化布局**：对齐可更精准
- **颜色可以更匹配**：接近但非完美匹配
- **交互状态优化**：悬停、点击状态可更丰富
- **动画平滑度**：可添加或优化过渡动画
- **响应式细节**：某些分辨率下可进一步优化

#### 处理标准
- 建议性改进，不强求
- 可作为技术债务处理
- 优先级由团队决定

---

## 颜色对比标准

### 色差计算方式
使用CIEDE2000标准计算色差（ΔE）

| ΔE值 | 视觉差异程度 | 等级 |
|------|-------------|------|
| < 1.0 | 不可察觉 | 无问题 |
| 1.0 - 2.0 | 细微差异 | 建议 |
| 2.0 - 10.0 | 轻微差异 | 次要 |
| 10.0 - 20.0 | 明显差异 | 主要 |
| > 20.0 | 完全不同 | 严重 |

### 可访问性标准
- **文本颜色对比度**：≥ 4.5:1（WCAG AA）
- **大文本对比度**：≥ 3:1（WCAG AA）
- **界面组件对比度**：≥ 3:1（WCAG AA）

## 尺寸和间距标准

### 容差范围

| 元素类型 | 位置偏差 | 尺寸偏差 | 间距偏差 |
|---------|---------|---------|---------|
| 主要组件 | ≤ 5px | ≤ 5px | ≤ 5px |
| 次要组件 | ≤ 10px | ≤ 10px | ≤ 10px |
| 装饰元素 | ≤ 15px | ≤ 15px | ≤ 15px |

### 布局对齐度
- **水平对齐**：偏差 ≤ 2px（优秀），≤ 5px（良好）
- **垂直对齐**：偏差 ≤ 2px（优秀），≤ 5px（良好）
- **网格对齐**：应按设计稿网格系统对齐

## 字体和文本标准

### 字体匹配度
| 属性 | 容许偏差 |
|------|---------|
| 字体族 | 必须完全匹配 |
| 字号 | ±1px |
| 字重 | 必须完全匹配 |
| 行高 | ±4px |
| 字间距 | ±0.5px |

### 文本样式
- **颜色**：应符合色差标准
- **对齐方式**：必须匹配设计稿
- **装饰效果**：下划线、删除线等应相同
- **截断处理**：省略号位置和显示应相同

## 交互状态对比

### 标准状态检查列表
- [ ] 默认状态（Normal）
- [ ] 悬停状态（Hover）
- [ ] 点击状态（Active）
- [ ] 焦点状态（Focus）
- [ ] 禁用状态（Disabled）
- [ ] 选中状态（Selected）

### 状态变化评价
- **过度动画**：时长、缓动函数应匹配
- **视觉反馈**：颜色、尺寸变化应一致
- **响应时间**：交互响应应无明显延迟

## 响应式适配标准

### 断点匹配
- 设计与实现应使用相同的断点
- 布局变化时机应一致
- 元素排列顺序应相同

### 缩放行为
- **等比缩放**：元素和间距应按比例缩放
- **文本缩放**：文本应保持可读性
- **图像适应**：图片应保持清晰度和比例

## 问题优先级判断流程

### 决策树
1. 是否影响核心功能或可用性？
   - 是 → **严重**
   - 否 → 继续

2. 是否影响主要视觉外观或品牌识别？
   - 是 → **主要**
   - 否 → 继续

3. 是否存在可察觉的视觉差异？
   - 是 → **次要**
   - 否 → 继续

4. 是否可以优化改进？
   - 是 → **建议**
   - 否 → 无问题

### 上下文考虑因素
- **用户使用频率**：高频功能问题优先级更高
- **页面重要性**：关键页面问题更严格
- **用户注意力区域**：首屏内容优先级更高
- **技术复杂度**：简单修复优先级更高

## 报告输出格式

### HTML报告包含
- 滑动对比区域
- 差异高亮显示
- 问题分类统计
- 详细问题清单
- 修复建议

### Markdown报告包含
- 总体评分（0-100）
- 问题分类计数
- 每个问题的详细描述
- 截图标注
- 修复步骤建议

### 输出文件命名
```
design-review-output/
├── design-review-report.html     # HTML报告
├── design-review-report.md       # Markdown报告  
├── visual-diff.png               # 差异高亮图
├── side-by-side.png              # 并排对比图
└── issues/                       # 问题标注截图
```

## 持续改进机制

### 团队协作流程
1. **设计提交**：设计师提供最新设计稿
2. **开发实现**：开发者按设计稿实现
3. **自动对比**：系统自动生成对比报告
4. **问题修复**：开发者根据报告修复问题
5. **验收确认**：设计师确认修复结果

### 质量指标跟踪
- **平均还原度**：团队整体设计还原水平
- **首要问题率**：严重和主要问题的占比
- **修复周期**：问题从发现到修复的平均时间
- **重复问题率**：相同问题再次出现的频率
